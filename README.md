# المهارات الرقمية – الصف العاشر (تطبيق أندرويد)

كتاب تفاعلي للوحدات الأربع: علم البيانات، البرمجة بلغة بايثون، المواطنة والأمان الرقمي، الروبوت ونظم التحكم — مع الإجابات والمحاكاة التفاعلية (ثنائية وثلاثية الأبعاد). يعمل بدون إنترنت.

## تنزيل التطبيق
افتح تبويب **Releases** في هذا المستودع، ثم نزّل `digital-skills-10.apk` من الإصدار **latest** وثبّته على الجهاز (قد يطلب الجهاز السماح بالتثبيت من مصادر غير معروفة).

## كيف يُبنى
كل دفع (push) إلى الفرع `main` يشغّل GitHub Actions فيبني ملف APK تلقائيًا وينشره في الإصدار `latest`.
يمكن أيضًا تشغيله يدويًا من تبويب **Actions ← Build Android APK ← Run workflow**.

## تحديث محتوى الكتاب
استبدل محتوى مجلد `www/` (الملف `index.html` ومجلد `img/`) ثم ادفع التغييرات؛ سيُبنى APK جديد تلقائيًا.

## البناء محليًا (اختياري)
```bash
npm ci
npx cap sync android
cd android && ./gradlew assembleDebug
```
يتطلب Android SDK و JDK 21.
